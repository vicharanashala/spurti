# Card Prompts

This directory contains the redesign prompts used to generate shareable achievement cards that are legible to external audiences (e.g., LinkedIn viewers with no program context).

## Files

- `points-milestone.md` — prompt for points-based milestone cards (e.g., "500+ Points Earned")
- `level-milestone.md` — prompt for general achievement/level milestone cards (e.g., "Completed 60 Hours of Focused Learning")

## Examples

Before/after sample card images will be added to `examples/` showing the readability improvement for external viewers.
