# Points-Milestone Card Prompt

Use this prompt to generate a shareable achievement card for a points-based milestone in a learning program.

---

Design a shareable "level milestone" achievement card for a learning program's points-based motivation system, written so someone outside the program understands it immediately.

**Context:** the platform awards points for learning activity (attendance, task completion, participation, etc.). "Level" is simply the point total divided into tiers (e.g., every 100 points = 1 level). It does not represent time, weeks, or a separate skill — it is a milestone marker for accumulated points. The card must be honest about this and not imply false meaning (e.g., don't claim it reflects consistency or duration if it doesn't).

**Structure:**

1. **Issuer branding** — logo + org name, top, small.
2. **Headline** — state it as a points milestone in plain terms, not a bare "Level N." E.g.:
   - "Crossed 500 Points in Program Engagement"
   - "Reached Milestone Tier 5"
   - "500+ Points Earned for Active Participation"
   Pick language that ties the number directly to effort/participation, since that's what the points actually measure.
3. **One-line plain-English explanation** beneath the headline — what points are earned for, e.g. "Points are earned by completing tasks, attending sessions, and staying active in the program. This milestone marks 500+ points earned."
4. **Recipient name + program/institution** — name, program name, host institution.
5. **Show the number with scale, not an isolated label.** Always pair "Level N" with either:
   - the actual point range it represents ("Level 5 · 500–599 points"), or
   - position toward a max ("Level 5 of 10 levels")
   A bare "Level 5" with no scale is meaningless to an outsider; showing the point threshold makes the achievement legible without needing to know the system.
6. **De-emphasize gamer framing** — avoid "ACHIEVEMENT UNLOCKED" banners and gold star/trophy icons that suggest competition or rank; use icons suggesting accumulation/growth (e.g., a rising bar chart, a filled progress ring, an ascending step icon).
7. **Verification QR/code** — retain for credibility.

**Tone:** certificate-style, professional, accurate — do not fabricate meaning (like implying "8 weeks of consistency") that the underlying point system doesn't actually track.

**Output:** single card, 1080x1350 (4:5 portrait), org brand colors, following the hierarchy above.
