# Level-Milestone / Achievement Card Prompt

Use this prompt to generate a shareable achievement card for a general milestone (not just points-based) in a learning program.

---

Design a shareable achievement/certificate card for a learning program, built so that someone with zero context about the program can still understand it in 5 seconds. Avoid internal jargon, unexplained point systems, and unexplained numeric levels as the headline.

**Structure:**

1. **Issuer branding (logo + org name)** — top, small, credible.
2. **Headline achievement, in plain human language** — describe what the person did or demonstrated, not a game-internal stat. E.g., instead of "3,600-Minute Club," say "Completed 60 Hours of Focused Learning." Instead of "Reached Level 5," say "Consistently Active for 8 Weeks" or name the underlying skill/behavior (e.g., "Completed 5 Real-World Projects," "Top 10% in Consistency").
3. **One-line explanation beneath the headline** — a plain-English sentence stating what this required or what it signals (e.g., "Awarded for showing up and completing daily learning tasks for 8 consecutive weeks without a gap.").
4. **Recipient name and program/institution context** — name, program name, and host institution, so a viewer immediately knows the setting (internship, course, bootcamp).
5. **Optional supporting stat, de-emphasized** — internal metrics (SP points, level number) can appear in small print at the bottom as "supporting detail," never as the headline, and always with a one-word label a stranger could look up (e.g., "Program Score: 805/1000" instead of "805 SPURTI POINTS").
6. **Verification QR/code** — keep this, it adds legitimacy for professional contexts.

**Tone:** professional, certificate-like, not arcade/gamer-like. Avoid emoji medal icons, "ACHIEVEMENT UNLOCKED" gamer language, and video-game color palettes (bright gold circles, trophy icons) unless replaced with icons that read as "skill" or "consistency" to a general audience (e.g., a checkmark, a calendar, a growth arrow) rather than "video game trophy."

**Output:** a single achievement card, 1080x1350 (4:5 portrait), in org's brand colors, following the above content hierarchy.
